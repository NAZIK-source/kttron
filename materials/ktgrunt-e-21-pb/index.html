Описание

«КТгрунт Э-21 ПБ» — эпоксидный грунтовочный состав для пористых бетонных поверхностей перед нанесением материалов серии «КТпротект». Может применяться как самостоятельное обеспыливающее покрытие.

Область применения

  • Для грунтования пористых бетонных поверхностей перед нанесением материалов серии «КТпротект».
  • Может служить в качестве самостоятельного покрытия для обеспыливания бетонных конструкций.

Достоинства

  • Паропроницаемое покрытие.
  • Высокая ударная прочность покрытия.
  • Малый расход.
