# kttron.kz

Сайт официального дистрибьютора КТ ТРОН в Казахстане (ТОО DARHAN).

Файлы лежат так же, как в `httpdocs` на хостинге (Plesk): содержимое репозитория копируется туда один в один.

```
.htaccess            настройки Apache (страница 404)
index.html           главная
404.html             страница «не найдено»
assets/              стили и скрипты (кэшируются браузером на 10 лет)
images/              фото товаров (p001–p050), сертификат, иконки
images/objects/      фото объектов (o001…), подключаются из скрипта
materials/           страницы ходовых материалов
calculator/          калькулятор расхода
objects/             реализованные объекты
gidroizolyaciya/     посадочная страница «Гидроизоляция»
kz/, tg/, uz/        версии на казахском, таджикском, узбекском
account/             личный кабинет клиента (PHP)
admin/               админка менеджера: заявки, оплаты, кэшбэк (PHP)
app/                 ядро кабинета, схема базы, настройки — закрыто от браузера
favicon.ico, favicon.svg, site.webmanifest, robots.txt, sitemap.xml
```

## Важно при правках

- Файлы в `assets/` браузеры кэшируют на 10 лет. Изменённый CSS/JS нужно сохранять под **новым именем** и менять ссылку в HTML, иначе посетители увидят старую версию. Мелкие правки стилей проще вносить в блок `<style>` в `index.html`.
- `main-B89Pv38-.js` используется внутренними страницами, `main-kt20260925.js` — главной.

## Откуда файлы

Страницы и картинки скачаны с работающего kttron.kz 20.10.2026: все страницы из `sitemap.xml` и всё, на что они ссылаются. Файлы, на которые сайт нигде не ссылается, если они есть на сервере, сюда не попали.

## Личный кабинет и кэшбэк

Клиент регистрируется по телефону и паролю. Заявки, которые он отправляет с сайта (корзина, калькулятор, форма «Написать специалисту»), сохраняются в кабинете и, как раньше, уходят в WhatsApp. Менеджер в `/admin/` отмечает заявку оплаченной и вводит сумму. Кэшбэк начисляется автоматически: `cashback_percent` от суммы, оплаченной деньгами. Баллами можно оплатить до `max_redeem_percent` заказа, 1 балл = 1 ₸.

### Первый запуск на хостинге

1. Plesk → «Базы данных» → «Добавить базу данных»: MySQL, кодировка utf8mb4. Запишите имя базы, пользователя и пароль.
2. Скопируйте `app/config.example.php` в `app/config.php` и впишите данные базы. В `setup_key` впишите длинный случайный ключ.
3. Откройте `https://kttron.kz/admin/setup.php`, введите ключ, логин и пароль администратора. Таблицы создадутся автоматически.
4. Сотрите `setup_key` в `app/config.php`. Страница настройки отключится и сама, как только появится первый администратор.

Файл `app/config.php` в репозиторий не попадает (`.gitignore`), потому что в нём пароль от базы.

### API для мобильного приложения

`account/app-api.php` — тот же кабинет для приложения: те же клиенты, заявки и баллы, что на сайте. Вместо cookie приложение передаёт токен в заголовке `X-Auth-Token` (или `Authorization: Bearer …`). В базе хранится только хэш токена (таблица `app_tokens`); она создаётся сама при первом входе из приложения. Токен перестаёт действовать, если приложением не пользовались полгода.

Действие — в `?a=`, данные — JSON в теле. Ответ: `{"ok": true, …}` или `{"ok": false, "error": "код", "message": "текст для клиента"}`.

| Запрос | Что делает |
|---|---|
| `GET ?a=config` | процент кэшбэка, лимит списания, WhatsApp менеджера |
| `POST ?a=register` `{name, phone, password, consent}` | регистрация, возвращает `token` и `user` |
| `POST ?a=login` `{phone, password}` | вход (лимит попыток общий с сайтом) |
| `POST ?a=logout` | выход с этого устройства |
| `GET ?a=me` | имя, телефон, баланс |
| `GET ?a=orders` | последние 100 заявок |
| `GET ?a=points` | баланс и история баллов |
| `POST ?a=order` `{text, source, want_redeem}` | новая заявка (те же лимиты, что на сайте) |
| `POST ?a=redeem` `{order, want}` | попросить списать баллы по новой заявке |
| `POST ?a=password` `{old, new}` | сменить пароль, выйти на других устройствах |
| `POST ?a=delete` `{password}` | удалить кабинет (требование App Store и Google Play): телефон и имя стираются, заявки и баллы остаются для учёта |

### Резервные копии

Баллы — это обязательства перед клиентами. Включите в Plesk «Резервное копирование» с базой данных хотя бы раз в сутки.

## Страницы товаров

У каждого из 50 товаров каталога своя страница `/materials/<slug>/` (для поиска: «КТтрон-3 Т400 Алматы» и т. п.). 42 из них собирает генератор:

```
python3 tools/build_product_pages.py
```

Он берёт данные из `index.html`, `specs.json`, `prices.json`, `calculator/index.html` и пересоздаёт страницы товаров, `materials/index.html`, `pages.json` и `sitemap.xml`. У 8 страниц, сделанных вручную (`kt-tron-1`, `-3`, `-7`, `-8`, `-10-1k`, `-10-2k`, `-101`, `-praymer`), генератор правит только заголовки, «Также пишут» и цену.

После смены цен в `prices.json` на страницах цена обновится сама (`kt-prices.js`), но для списка материалов и разметки Product в поиске генератор лучше перезапустить.

## Страницы под запросы

`python3 tools/build_landing_pages.py` собирает страницы «Гидроизоляция фундамента / подвала / бассейна» (`/gidroizolyaciya/fundamenta/` и т. д.) и «Ремонт бетона» (`/remont-betona/`), а на `/gidroizolyaciya/` обновляет таблицу «Цены на гидроизоляцию за 1 м²» (список `GIDRO_TABLE`) и ответ «Сколько стоит гидроизоляция в Алматы?». Тексты и подбор материалов — в списке `PAGES` в начале файла (по «Области применения» из описаний завода); примеры расчёта считаются по нормам завода и `prices.json`, поэтому после смены цен генератор стоит перезапустить.
