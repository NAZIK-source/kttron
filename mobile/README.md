# Приложение КТ ТРОН для iOS и Android

Flutter, один код на обе платформы. Кабинет, заявки и кэшбэк общие с сайтом kttron.kz.

## Что внутри

| Вкладка | Что делает | Откуда данные |
|---|---|---|
| Каталог | 50 материалов: поиск, разделы, цены «от», характеристики, ссылки на техописания | `app-data.json` |
| Подбор | Задачи (фундамент, подвал, бассейн, ремонт бетона): материалы, порядок работ, вопросы | `app-data.json` |
| Расчёт | Калькулятор расхода по нормам завода — тот же расчёт, что на `/calculator/` | `app-data.json` |
| Заявка | Корзина → заявка уходит менеджеру в WhatsApp и сохраняется в кабинете | `account/app-api.php` |
| Кабинет | Вход и регистрация, баланс, заявки, история баллов, списание, смена пароля, удаление кабинета | `account/app-api.php` |

Каталог приложение скачивает с `https://kttron.kz/app-data.json` при каждом запуске, поэтому цены и товары обновляются без новой версии в App Store и Google Play. Копия вшита в приложение (`assets/app-data.json`) на случай первого запуска без интернета.

```
lib/main.dart          запуск, тема, нижнее меню
lib/api.dart           запросы к кабинету на сайте
lib/catalog.dart       каталог, калькулятор, подбор
lib/state.dart         заявка (корзина) и вход
lib/screens/           экраны
assets/app-data.json   вшитая копия каталога (собирает tools/build_app_data.py)
assets/icon/           иконка из логотипа сайта
```

## Что сделать на сайте перед выпуском

1. Залить на хостинг `account/app-api.php` и `app-data.json` (как обычно: содержимое репозитория в `httpdocs`). Таблица `app_tokens` создастся сама при первом входе из приложения.
2. После смены цен, товаров или калькулятора: `python3 tools/build_app_data.py` в корне репозитория и залить обновлённый `app-data.json`.

## Сборка

Нужны [Flutter](https://docs.flutter.dev/get-started/install) 3.47+, для iOS — Mac с Xcode, для Android — Android Studio.

```
cd mobile
flutter pub get
flutter test                 # проверки расчёта и заявки
flutter run                  # на подключённом телефоне или эмуляторе
flutter build appbundle      # Android → Google Play
flutter build ipa            # iOS → App Store (только на Mac)
```

Проверить на тестовом сервере вместо kttron.kz: `flutter run --dart-define=SITE=https://адрес-теста`.

Идентификатор приложения: `kz.kttron.app` (iOS и Android). После публикации его менять нельзя.

## Публикация

1. **Аккаунты разработчика на ТОО DARHAN**, не на подрядчика: Apple Developer Program ($99 в год, нужен D-U-N-S номер компании) и Google Play Console ($25 один раз).
2. **Android:** создать ключ подписи (`keytool`), прописать в `android/key.properties`, собрать `flutter build appbundle`, загрузить в Play Console. Ключ хранить в надёжном месте — без него не выпустить обновление.
3. **iOS:** в Xcode выбрать команду разработчика (Signing & Capabilities), собрать `flutter build ipa`, загрузить через Transporter или Xcode.
4. Для карточек в магазинах: скриншоты, описание, ссылка на политику конфиденциальности (можно `https://kttron.kz/account/rules.php`, раздел 4), контакт поддержки.
5. Для проверки Apple и Google дать тестовый кабинет (телефон и пароль) в поле «Данные для входа».

Удаление кабинета прямо из приложения уже есть (меню кабинета → «Удалить кабинет») — это обязательное требование обоих магазинов.
