# Приложение КТ ТРОН для iOS и Android

Flutter, один код на обе платформы. Кабинет, заявки и кэшбэк общие с сайтом kttron.kz.

## Что внутри

| Вкладка | Что делает | Откуда данные |
|---|---|---|
| Каталог | 50 материалов: поиск, разделы, цены «от», характеристики, ссылки на техописания | `app-data.json` |
| Подбор | Задачи (фундамент, подвал, бассейн, ремонт бетона): материалы, порядок работ, вопросы | `app-data.json` |
| Расчёт | Калькулятор расхода по нормам завода — тот же расчёт, что на `/calculator/` | `app-data.json` |
| Заявка | Корзина → заявка уходит менеджеру в WhatsApp и сохраняется в кабинете | `account/app-api.php` |
| Кабинет | Вход и регистрация, баланс, заявки, история баллов, списание, смена пароля, удаление кабинета | `account/app-api.php` |

Каталог приложение скачивает с `https://kttron.kz/app-data.json` при каждом запуске, поэтому цены и товары обновляются без новой версии в App Store и Google Play. Копия вшита в приложение (`assets/app-data.json`) на случай первого запуска без интернета.

```
lib/main.dart          запуск, тема, нижнее меню
lib/api.dart           запросы к кабинету на сайте
lib/catalog.dart       каталог, калькулятор, подбор
lib/state.dart         заявка (корзина) и вход
lib/screens/           экраны
assets/app-data.json   вшитая копия каталога (собирает tools/build_app_data.py)
assets/icon/           иконка из логотипа сайта
```

## Что сделать на сайте перед выпуском

1. Залить на хостинг `account/app-api.php` и `app-data.json` (как обычно: содержимое репозитория в `httpdocs`). Таблица `app_tokens` создастся сама при первом входе из приложения.
2. После смены цен, товаров или калькулятора: `python3 tools/build_app_data.py` в корне репозитория и залить обновлённый `app-data.json`.

## Сборка

Нужны [Flutter](https://docs.flutter.dev/get-started/install) 3.47+ и Android Studio (или Android SDK). Для iOS — Mac с Xcode.

```
cd mobile
flutter pub get
flutter test                 # проверки расчёта и заявки
flutter run                  # на подключённом телефоне или эмуляторе
flutter build appbundle      # Android → Google Play
flutter build ipa            # iOS → App Store (только на Mac)
```

Проверить на тестовом сервере вместо kttron.kz: `flutter run --dart-define=SITE=https://адрес-теста`.

Идентификатор приложения: `kz.kttron.app`. После публикации его менять нельзя.

## Публикация в Google Play (первый этап — только Android)

iOS-версия собирается из того же кода, но пока не публикуется.

1. **Аккаунт Google Play Console на ТОО DARHAN** ($25 один раз): play.google.com/console → «Организация». Проверка документов компании занимает несколько дней.
2. **Ключ подписи.** Создайте файл `android/key.properties` (в репозиторий не попадает):
   ```
   storeFile=/полный/путь/к/kttron-upload.jks
   storePassword=…
   keyAlias=upload
   keyPassword=…
   ```
   Без этого файла релиз подписывается отладочным ключом: такой APK ставится на телефон для проверки, но Google Play его не примет. Ключ храните в надёжном месте: им подписывается каждое обновление (при потере его можно заменить через поддержку Google Play, но это долго).
3. **Сборка:** `flutter build appbundle` → файл `build/app/outputs/bundle/release/app-release.aab`. Для проверки на телефоне: `flutter build apk` → `build/app/outputs/flutter-apk/app-release.apk`.
4. **Play Console → «Создать приложение»**, включить Play App Signing (по умолчанию), загрузить `.aab` сначала во «Внутреннее тестирование».
5. **Карточка приложения:** название «КТ ТРОН Казахстан», краткое и полное описание, иконка 512×512 (`assets/icon/icon.png`), картинка 1024×500, 2–8 скриншотов с телефона.
6. **Анкеты в Play Console:** политика конфиденциальности (`https://kttron.kz/account/rules.php`, раздел 4), «Безопасность данных» (собираются имя и телефон для кабинета, не передаются третьим лицам, можно удалить в приложении), возрастной рейтинг, целевая аудитория (18+), реклама — нет.
7. Для проверки Google дайте тестовый кабинет (телефон и пароль) в разделе «Доступ к приложению».
8. Новый личный аккаунт разработчика Google обязывает 14 дней закрытого тестирования с 12 тестировщиками; аккаунт организации от этого освобождён — ещё одна причина регистрировать на ТОО.

Удаление кабинета прямо из приложения уже есть (меню кабинета → «Удалить кабинет») — это обязательное требование Google Play.

**Обновление:** увеличить `version` в `pubspec.yaml` (например `1.0.1+2`; число после `+` должно расти с каждой загрузкой), собрать `flutter build appbundle`, загрузить в Play Console.
